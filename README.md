# Finkom Store

E-commerce website for a building materials store in Pryluky.

## Core features

- Product catalog
- Product detail pages
- Cart
- Checkout
- Address delivery
- Product units: pcs, m2, m, kg, l, pack
- 1C/BAS integration for catalog, stock, prices and orders

## Tech stack

- Next.js
- TypeScript
- PostgreSQL
- Prisma
- Tailwind CSS
- 1C/BAS integration API
